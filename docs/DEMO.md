# Демо в репозитории

Этот проект теперь содержит быстрый локальный демо-сценарий, который можно запустить одной командой.

## Быстрый запуск

```bash
./scripts/run_demo.sh
```

Скрипт:
1. Поднимает `backend + frontend` через `docker compose up -d --build`.
2. Проверяет health backend (`/health`).
3. Создает демо-протокол через `POST /api/demo/bootstrap`.
4. Выводит прямые ссылки на страницы `Normalize` и `Confirm`.

## Что посмотреть в демо

1. **Normalize**: фильтры `Без темы/исполнителя/срока`, `Только ошибки`, `Неподтвержденные`, `Готовые к публикации`.
2. **Массовые операции**: назначение темы, массовый исполнитель, массовый срок, исключение из публикации, удаление.
3. **Confirm**: validate, generate/download docx, publish в Bitrix24 mock.

## Остановка

```bash
docker compose down
```
